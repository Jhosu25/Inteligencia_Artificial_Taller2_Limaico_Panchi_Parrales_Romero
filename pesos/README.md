# pesos/

Acá va el archivo `model.h5` (pesos entrenados del modelo EfficientNetB0 + Transfer
Learning sobre Caltech Birds 2011, generado en el Colab del Taller 2).

El archivo **no se versiona en Git** (es un binario pesado, ~29 MB) — cada quien debe
copiar su propio `model.h5` en esta carpeta antes de levantar el backend Flask (`app.py`).

Si no lo tienes, córrelo desde `Copia_de_Transfer_Learning.ipynb` en Colab y descarga el
`model.h5` que genera al final del entrenamiento.
